# Credit Card Fraud Detection

## Overview
This project detects fraudulent credit card transactions using machine learning. It is a classification problem where the model predicts whether a transaction is genuine or fraudulent.

## Dataset
The dataset contains transaction details such as:
- Transaction amount
- Time
- Other anonymized features

The target variable indicates whether a transaction is fraud (1) or not (0).

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Approach
- Load the dataset
- Explore and preprocess the data
- Split into training and testing sets
- Train a classification model
- Evaluate model performance

## Result
The model is able to identify fraudulent transactions with good accuracy.

## Conclusion
This project demonstrates how machine learning can be used for fraud detection in financial data.
