
# Credit Card Fraud Detection

## Overview
This project detects fraudulent credit card transactions using machine learning.

## Dataset
The dataset contains transaction details and a target column indicating fraud or not.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Approach
- Load dataset
- Preprocess data
- Train model
- Evaluate performance

## Result
The model can identify fraudulent transactions with good accuracy.

## Note
Dataset is not uploaded due to large file size. It can be downloaded from Kaggle.
