# Titanic Survival Prediction

## Overview
This project predicts whether a passenger survived the Titanic disaster using machine learning. It is a basic classification problem that helps understand how models work with real-world data.

## Dataset
The dataset includes passenger details such as age, gender, passenger class, and fare. These features are used to predict survival.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Approach
- Load the dataset
- Handle missing values
- Convert categorical data into numerical form
- Split the data into training and testing sets
- Train a machine learning model
- Evaluate the model performance

## Result
The model predicts whether a passenger survived based on input features with reasonable accuracy.

## Conclusion
This project demonstrates the basics of classification and data preprocessing in machine learning.

## Learning Outcome
- Data cleaning and preprocessing
- Working with datasets using Pandas
- Training and testing machine learning models
