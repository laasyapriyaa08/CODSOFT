# Iris Flower Classification

## Overview
This project classifies iris flowers into three species: Setosa, Versicolor, and Virginica using machine learning. It is a basic classification problem used to understand how models learn patterns from data.

## Dataset
The dataset contains measurements of flowers:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

These features are used to predict the species of the flower.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Approach
- Load the dataset
- Explore and clean the data
- Split data into training and testing sets
- Train a classification model
- Evaluate model performance

## Result
The model classifies iris flowers into correct species with good accuracy.

## Conclusion
This project demonstrates the basics of classification and machine learning workflow.
